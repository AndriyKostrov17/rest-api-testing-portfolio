# REST API Testing — WordPress API & PostgreSQL Practice

## Project Overview

This portfolio project demonstrates practical knowledge of REST API testing, API documentation analysis, request and response validation, and SQL queries.

The project combines API exploration, test scenario design, and database query practice using separate learning environments.

## Objectives

- Analyze REST API endpoints and their documentation.
- Identify request parameters, response structures, and HTTP status codes.
- Design positive, negative, and boundary test scenarios.
- Validate API responses using Postman.
- Practice SQL queries for data verification using PostgreSQL.
- Document test results and findings.

## Tools and Technologies

- Postman
- REST API
- JSON
- Swagger / OpenAPI
- PostgreSQL
- SQL
- Markdown

## Project Scope

The project includes three separate practice areas:

1. **WordPress REST API** — exploration of publicly accessible endpoints and response structures.
2. **Swagger Petstore API** — documentation analysis and endpoint testing practice.
3. **PostgreSQL Sakila database** — SQL exercises for data retrieval and verification.

These are separate environments used for different learning objectives.

## Testing Activities

- Endpoint and parameter analysis
- HTTP method and status code validation
- Positive and negative test scenario design
- Response structure and data validation
- SQL queries using filtering, sorting, aggregation, and joins
- Test documentation and reporting

## Limitations

- No access to the WordPress project's private database.
- No claim of commercial backend QA experience based on this learning project.
- No production load or stress testing performed as part of this project.
- Results will reflect only the checks actually executed and documented.
